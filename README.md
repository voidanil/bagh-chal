# 🐯 Bagh-Chal Game

A simple web-based version of the traditional Nepali strategy game **Bagh-Chal**, where 4 Tigers compete against 20 Goats.

## 🎮 Demo

👉 [Play Bagh-Chal Online](https://bagh-chal.vercel.app/)

## ✨ Features

- 🐯 4 Tigers
- 🐐 20 Goats
- 🎯 Tiger capture system
- 🏆 Win/lose conditions
- 🔄 Restart game

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Run Locally

```bash
git clone https://github.com/voidanil/bagh-chal.git
cd bagh-chal
```
